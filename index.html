Method

  • catalogue: CDP x402 Bazaar discovery list, full offset traversal every 6 hours since 2026-09-14.
  • noise: qualification_burst = a provider's listings showing identical tiny calls==payers stamped in the same minute; such counters are index pings, not demand.
  • probe: One unpaid request per resource with the declared method; a 402 challenge means the gate is up. No payment header is ever sent.
  • settlement: USDC Transfer logs on Base to the listed payTo address. Counts transfers from any sender, so non-x402 income is included; listed_seller_payers counts payers that are themselves listed sellers.
  • verdict: verified_paid = live and at least one on-chain payer in 30 days to this resource's own payTo that is not a listed seller; verified_entity_paid = same evidence but the payTo is shared by several listings, so only the operator is verified; live_catalogue_signal = live with >=3 reported payers and no noise label; dead_listing = last probe unreachable, 5xx or 404.
