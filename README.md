# x402 Observer — public index

Static export of a read-only census of the Coinbase x402 Bazaar discovery catalogue, probed
daily for liveness without ever paying. Every figure is labelled by how it was obtained
(catalogue counter, unpaid probe, on-chain settlement). Catalogue counters are not sales
evidence. Rebuilt nightly.

- `index.html` — human summary
- `index.json` — summary, top entities, top resources
- `resources.json` — every non-burst listing with its verdict
- `entities.json` — payTo-based entities
- `weekly/` — weekly markdown reports
